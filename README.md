## Данные

Ноутбуки читают данные прямо по ссылке, скачивать ничего не надо:

```python
DATA = "https://raw.githubusercontent.com/nvvoitov/da_intro/main/data/"
panel = pd.read_parquet(DATA + "banks_panel.parquet")
```

| Файл | Что внутри |
|---|---|
| `banks_panel.parquet` | квартальная отчётность банков США, 2001–2026: 152 152 наблюдения «банк-квартал», 2586 банков, признаки CAMELS уже посчитаны |
| `failures.parquet` | банкротства: дата, тип урегулирования, стоимость для фонда страхования |
| `macro.parquet` | макропоказатели |
| `sod.parquet` | депозиты в разрезе отделений (Summary of Deposits) |

Денежные величины — **в тысячах долларов**.
