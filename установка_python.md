# Как установить Python

Два пути. **Выберите один!**

---

## Путь 1. Ничего не устанавливать: Google Colab

Ничего ставить не надо. Открываете ссылку на ноутбук в браузере, нажимаете «Копировать на Диск» — и работаете. Python, все библиотеки и даже GPU (разумеется, с лимитами) там есть. Все ноутбуки курса написаны так, чтобы открываться в Colab и запускаться без дополнительных действий.

Ссылки «Открыть в Colab» — в [README](README.md).

**Недостатки**: сессия живёт несколько часов, потом среда сбрасывается, и всё посчитанное придётся считать заново. Файлы, которые вы создали внутри Colab, тоже исчезнут — сохранённой остаётся только копия ноутбука на вашем Google Диске.

**Если не чувствуете сил ставить питон — пользуйтесь Colab.** К локальной установке вернётесь, когда она вам зачем-нибудь понадобится.

## Путь 2. Локальная установка: Python + VS Code + Jupyter

*Занимает около 10 минут.* Порядок строго такой (он простой).

### Шаг 1. Установить Python — сам язык

**Windows.** Скачайте установщик с [python.org/downloads](https://www.python.org/downloads/). В первом же окне поставьте галочку **«Add python.exe to PATH»** — она внизу, её все пропускают, и потом появляется миллион ошибок в духе «python не является внутренней или внешней командой». Галочка нужна, чтобы программы из шага 2 знали, где на вашем компьютере лежит Python. Дальше «Install Now».

**macOS.** Скачайте установщик с [python.org/downloads](https://www.python.org/downloads/) и прокликайте до конца. **Встроенный в macOS Python трогать не надо** (такой там есть) — он системный, и ставить в него пакеты не стоит.

**Проверка.** Откройте терминал (Windows: `Win+R` → `cmd`; macOS: Spotlight → «Терминал») и наберите — на Windows:

```
python --version
```

на macOS:

```
python3 --version
```

Должно напечататься `Python 3.11` или новее (главное — не ошибка). Если пишет «команда не найдена»: на Windows переустановите с галочкой PATH, на macOS попробуйте `python3` вместо `python`.

> Не копируйте в терминал строки с `#` и пояснениями после команды. В macOS-терминале `#` — это комментарий, а в Windows `cmd` — нет, и команда сломается. Копируйте только саму команду.

### Шаг 2. Установить VS Code — интерфейс для работы с питоном

Скачайте с [code.visualstudio.com](https://code.visualstudio.com/), установите. Внутри слева — иконка «Extensions» (квадратики). Найдите и поставьте два расширения от Microsoft: **Python** и **Jupyter**.

### Шаг 3. Папка проекта и библиотеки

В терминале (Windows: `Win+R` → `cmd`; macOS: Spotlight → «Терминал») выполняйте команды **построчно**: скопировали строку — `Enter` — следующая.

**Windows** (именно `cmd`, не PowerShell):

```
mkdir da_course
cd da_course
py -m venv .venv
.venv\Scripts\activate
pip install numpy pandas matplotlib seaborn scikit-learn statsmodels pyarrow jupyter
```

**macOS**:

```
mkdir da_course
cd da_course
python3 -m venv .venv
source .venv/bin/activate
pip install numpy pandas matplotlib seaborn scikit-learn statsmodels pyarrow jupyter
```

`venv` — это отдельная коробка с библиотеками под конкретный проект. Что-то вроде отдельной папки под курсовую: в одной коробке одни версии библиотек, в другой другие, и они друг другу не мешают. Признак, что коробка включена: в начале строки терминала появилось `(.venv)`.

Что мы поставили: `pandas` (таблицы), `numpy` (математика), `matplotlib` и `seaborn` (графики), `scikit-learn` (модели), `statsmodels` (регрессии с t-статистиками), `pyarrow` (чтение файлов `.parquet`), `jupyter` (сами ноутбуки).

> **Если вы в PowerShell, а не в `cmd`** (в VS Code терминал по умолчанию именно PowerShell): активация пишется иначе — `.\.venv\Scripts\Activate.ps1`. Если PowerShell отвечает, что выполнение сценариев запрещено, выполните один раз `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и ответьте `Y`. Или просто откройте `cmd` и работайте в нём.

### Шаг 4. Запуск

В VS Code: `File → Open Folder` → ваша папка `da_course`. Скачайте туда ноутбук курса, откройте `.ipynb`, справа сверху нажмите **«Select Kernel»** и выберите тот, где в пути есть `.venv`. Всё, ячейки запускаются по `Shift+Enter`.

Данные скачивать не нужно: ноутбуки читают их прямо по ссылке из интернета.

## Что ломается чаще всего

| Ошибка | Причина | Лечение |
|---|---|---|
| `python не является внутренней командой` | не поставили галочку PATH | переустановить Python с галочкой |
| `pip: command not found` | не активирован venv | `.venv\Scripts\activate` / `source .venv/bin/activate` |
| PowerShell: `невозможно загрузить файл ... Activate.ps1` | политика выполнения сценариев | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или работать в `cmd` |
| В VS Code нет нужного ядра | окно открыто не как папка | `File → Open Folder`, затем «Select Kernel» |
| `ModuleNotFoundError: No module named 'pandas'` | пакет поставлен в другой venv | проверьте `(.venv)` в строке терминала и переставьте пакет |
| `ModuleNotFoundError: No module named 'pyarrow'` | нет библиотеки для `.parquet` | `pip install pyarrow` |
| Всё сломалось за 15 минут до сдачи | — | открываете Colab и не мучайтесь |
